# Дословная посекундная расшифровка аудио

`transcribe.py` превращает аудио или видео в текст слово в слово, с таймкодом на каждую секунду.
Работает локально на [faster-whisper](https://github.com/SYSTRAN/faster-whisper), без платных API.

## Установка

```bash
pip install -r requirements.txt
```

Нужен `ffmpeg` для mp3/ogg/m4a/mp4 (`brew install ffmpeg` / `apt install ffmpeg`).
При первом запуске модель скачивается с HuggingFace: medium весит ~1.5 ГБ, large-v3 ~3 ГБ.

## Запуск

```bash
python transcribe.py запись.mp3
```

Вывод (а также файлы `запись.txt`, `запись.srt`, `запись.json` рядом с исходником):

```
[00:00:00] Привет, эм, это
[00:00:01] тестовая запись,
[00:00:03] ну, в общем...
```

Каждое слово попадает в ту секунду, в которой оно началось (по пословным таймкодам Whisper).

## Опции

| Флаг | Что делает |
|---|---|
| `--model large-v3` | точнее, но медленнее (по умолчанию `medium`; есть `tiny`, `base`, `small`) |
| `--language auto` | автоопределение языка (по умолчанию `ru`) |
| `--empty-seconds` | строка на каждую секунду, включая тишину |
| `--formats txt,srt,json` | какие файлы сохранять |
| `--out-dir out/` | папка для результатов |
| `--device cuda` | считать на видеокарте NVIDIA |
| `--no-verbatim` | не сохранять слова-паразиты и повторы («эм», «ну», «это самое») |

В JSON, кроме посекундных строк, лежит список всех слов с точными `start`/`end` (до миллисекунд)
и уверенностью модели `prob`. По нему можно найти места, которые стоит перепроверить на слух.
